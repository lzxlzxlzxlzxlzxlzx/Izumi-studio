## 1. 设计原则与约定

### 1.1 原则

| 原则 | 说明 |
|------|------|
| **单一职责** | 每模块仅一个核心功能，边界不在模块间的胶水代码 |
| **接口隔离** | 入参/出参均为纯数据结构（I 前缀类型），不作隐式传递 |
| **无全局状态** | 模块实例可通过 `config: T` 持有配置，但不读取全局变量 |
| **可替换性** | 同接口可对应多实现（如 LLMRouter 的 provider 实现） |
| **独立可测** | 模块的所有依赖均可 mock，测试不启动完整服务 |

### 1.2 方法签名规范

```python
# 所有公共方法遵循统一签名：
async def method_name(
    input: I_XXXX_Input,      # 入参：Pydantic BaseModel
    config: ModuleConfig       # 模块配置（可选）
) -> I_XXXX_Output:            # 出参：Pydantic BaseModel
```

- 输入/输出均使用 Pydantic BaseModel 包装，保持与 TypeScript 类型结构一致
- 异步方法通过 `asyncio` 实现（I/O 操作）或 `run_in_executor`（CPU 密集操作）
- 错误统一通过 `raise ModuleError(code, message)` 抛出

### 1.3 测试约定

- 每个模块至少包含：`test_unit.py`（单元测试）、`test_integration.py`（集成测试）
- Mock 依赖通过 `unittest.mock.patch` 注入，不启动真实 LLM / DB
- 集成测试使用 SQLite `:memory:` 和文件系统 `tmp_path`

#### 3.1.3 核心算法

```
1. 检测文件格式

2. 验证 spec 字段
   ├── spec == "chara_card_v3" → 走 V3 解析
   └── 其他 → 返回错误

3. V3 解析
   ├── data.name → ICharacterCard.name
   ├── data.description → ICharacterCard.description
   ├── data.extensions → ICharacterCard.extensions
   ├── data.personality → ICharacterDefinition.personality
   ├── data.scenario → ICharacterDefinition.scenario
   ├── data.first_mes → ICharacterDefinition.first_mes
   ├── data.mes_example → ICharacterDefinition.mes_example
   ├── data.creator_notes → ICharacterDefinition.creator_notes
   ├── data.alternate_greetings → ICharacterDefinition.alternate_greetings
   ├── data.tags → ICharacterCard.tags
   ├── data.system_prompt → ICharacterCard.system_prompt
   ├── data.post_history_instructions → ICharacterCard.post_history_instructions
   ├── data.extensions.depth_prompt → ICharacterCard.depth_prompt
   ├── data.extensions.world → ICharacterCard.worldbook_ids + IWorldBook(内联)
   └── data.extensions.npcs → ICharacterDefinition.npcs (新版自定义属性)

4. 写入数据库 → 返回 ICharacterCard
```

```
instantiateAutoActive(card, session_id):

  for npc in card.character.npcs:
    if npc.start_active:
      character = IStoryCharacter(
        id          = new_uuid(),
        session_id  = session_id,
        name        = npc.name,
```

#### 3.3.3 核心算法

**重建注册表 (build):**
```
build(session_id, card, upto_message_index):
  1. 从 card.character.npcs (start_active=true) 初始化注册表
  2. 加载 ICharacterChangeLog WHERE session_id = ? AND message_index <= upto
  3. 按 (message_index, timestamp) 顺序重放:
     for log in logs:
       if log.action == 'create':
         创建 IStoryCharacter, 填入 log.changes 的 new_value
       elif log.action == 'update':
         找到角色, 对每个 change:
           if change.new_value is None: 删除属性
           else: 设置属性 = new_value
       elif log.action == 'delete':
         从注册表移除角色
  4. 返回 ICharacterRegistry
```

**Skill 处理 (processSkillCall):**
```
processSkillCall(session_id, message_id, message_index, tool_call):
  op = tool_call.function.name   # 如 "create_character"
  args = JSON.parse(tool_call.function.arguments)

  registry = build(session_id, card, message_index - 1)  # 前一状态的注册表

  match op:
    case 'list_characters':
      result = filter(registry.characters, args.filter)
    case 'get_character':
      result = find_by_name(registry.characters, args.name)
    case 'create_character':
      new_char = IStoryCharacter({
        name: args.name,
        attributes: args.attributes or {},
        is_active: args.is_active ?? True,
        is_alive: args.is_alive ?? True,
        ...
      })
      changelog = buildChangeLog('create', new_char, message_id, message_index)
      save(changelog)
      result = new_char
    case 'update_character':
      char = find_by_name(registry.characters, args.name)
      changes = diff(old_attrs, new_attrs)
      changelog = buildChangeLog('update', changes, message_id, message_index)
      save(changelog)
      result = patched_char
    case 'delete_character':
      char = find_by_name(registry.characters, args.name)
      changelog = buildChangeLog('delete', char, message_id, message_index)
      save(changelog)
      result = success

  return SkillResult
```

**回溯 (rollback):**
```
rollback(session_id, target_message_index):
  1. DELETE FROM character_change_logs WHERE message_index > target
  2. return build(session_id, card, target_message_index)
```

#### 3.4.3 核心算法

**扫描流程 (scan):**
```
scan(input):
  1. 构建扫描缓冲区
     buffers = [
        flatten_chat_history(input.chat_history),   # 拼接所有消息文本
        input.extra_buffers.persona_desc,           # 扩展来源
        input.extra_buffers.char_desc,
        input.extra_buffers.char_personality,
        input.extra_buffers.char_scenario,
     ]

  2. 遍历所有 worldbook 的所有 entry:
     for entry in entries:
       # 前置检查
       if not entry.enabled: continue
       if entry.delay > input.state.round_count: continue
       if entry.id in input.state.cooldown_map: continue  # 冷却中

       # 关键词匹配
       matched = matchKeywords(entry, buffers)
       if not matched: continue

       # 概率检查
       if entry.probability < 100:
         if random(0, 100) > entry.probability: continue

       # 通过 → 加入激活列表
       activated.append(entry)

       # 时序效果
       if entry.sticky > 0:
         input.state.sticky_map[entry.id] = entry.sticky
       if entry.cooldown > 0:
         remove_from_sticky_if_exists(entry.id)
         input.state.cooldown_map[entry.id] = entry.cooldown

  3. 分组评分
     for group_name, group_entries in group_by(activated, 'group'):
       keep max(group_entries, key=lambda e: e.group_weight)

  4. Token 预算裁剪
     sorted = sort(activated, key=lambda e: -e.priority)
     result = []
     for entry in sorted:
       if token_budget - calcTokens(entry.content) >= 0:
         result.append(entry)
         token_budget -= calcTokens(entry.content)
       else:
         break

  5. 递归扫描（如启用）
     if worldbook.recursive_scanning:
       new_content = join(entry.content for entry in result if not entry.prevent_recursion)
       buffers.append(new_content)
       goto 2 (最多 max_recursion_steps 次)

  6. 按 position 分类输出
     return IWorldBookActivationResult{
       before_char: [e for e in result if e.position == 'before_char'],
       after_char:  [e for e in result if e.position == 'after_char'],
       at_depth:    [...],
       examples:    [...],
       an_top:      [...], an_bottom: [...],
       em_top:      [...], em_bottom: [...],
       outlet:      [...],
       updated_state: input.state,
       trimmed_count: total_activated - len(result),
     }
```

**关键词匹配逻辑:**
```
matchKeywords(entry, buffers):
  text = join(buffers)
  primary_hit = any(key in text (with opts) for key in entry.keys)

  if not primary_hit: return False
  if not entry.keys_secondary: return True   # 无次关键词 → 命中即触发

  secondary_hit_count = count(entry.keys_secondary, text)
  secondary_all_hit = (secondary_hit_count == len(entry.keys_secondary))

  match entry.selective_logic:
    case AND_ANY:  return secondary_hit_count >= 1
    case AND_ALL:  return secondary_all_hit
    case NOT_ANY:  return secondary_hit_count == 0
    case NOT_ALL:  return not secondary_all_hit
```

**触发摘要生成 (checkAndTrigger):**
```
checkAndTrigger(session_id, chat_history, config, llm):
  round_count = max(msg.round_index for msg in chat_history)
  existing_summaries = fetchSummaries(session_id)

  last_summary_end = max(s.segment_end for s in existing_summaries) if existing_summaries else 0

  # 检查是否需要生成
  if round_count - last_summary_end < config.summary_interval:
    return None   # 未到间隔

  # 需摘要的区间
  segment_start = last_summary_end + 1
  segment_end = round_count

  # 提取该区间的消息
  segment_messages = [m for m in chat_history
                      if segment_start <= m.round_index <= segment_end]

  # 调用 LLM 生成摘要
  summary_text = await llm.summarize(
    model=config.summary_model,
    template=config.summary_template,
    messages=segment_messages,
    previous_summaries=existing_summaries,  # 之前摘要作为上下文
  )

  summary = IMemorySummary{
    id: uuid4(),
    session_id,
    segment_start, segment_end,
    summary: summary_text,
    key_events: extractKeyEvents(summary_text),
    state_snapshot: {},
    locked: False,
    created_at: now(),
  }

  save(summary)
  return summary
```

#### 3.9.3 核心算法

**组装流程:**
```
assemble(input):
  # ====== 阶段 1: 渲染 system prompt ======
  rendered_story = TemplateRenderer.render({
    template: input.context_config.story_string,
    vars: {
      system: input.system_prompt_override or input.character.system_prompt,
      description: input.character.character.description,
      personality: input.character.character.personality,
      scenario: input.character.character.scenario,
      persona: input.persona?.description,
      wiBefore: formatWorldInfo(input.worldbook.before_char),
      wiAfter: formatWorldInfo(input.worldbook.after_char),
      mesExamples: input.character.character.mes_example,
      char: input.character.character.name,
      user: input.persona?.name,
    }
  })

  # ====== 阶段 2: 构建 System Prompt 区域 ======
  system_messages = []
  for prompt in input.prompt_collection.prompts:
    if prompt.role != 'system': continue

    match prompt.identifier:
      case 'main':
        content = rendered_story
      case 'charDescription':
        content = input.character.character.description
      case 'charPersonality':
        content = charFormat(input.personality_format, input.character)
      case 'scenario':
        content = input.character.character.scenario
      case 'worldInfoBefore':
        content = joinFormatted(input.worldbook.before_char)
      case 'worldInfoAfter':
        content = joinFormatted(input.worldbook.after_char)
      case 'dialogueExamples':
        content = formatExamples(input.character.character.mes_example)
      case 'personaDescription':
        content = input.persona?.description or ""
      case 'summary':
        content = joinSummaries(input.memory.summaries)
      case 'jailbreak':
        content = input.jailbreak_override
                   or input.character.post_history_instructions
                   or prompt.content
      case 'nsfw':
        content = prompt.content  # 提示文本
      case _:
        if not prompt.marker:
          content = prompt.content
        else:
          continue  # 未处理的 marker 跳过

    system_messages.append(IRawChatMessage(role='system', content=content))

  # ====== 阶段 3: 构建 Chat History 区域 ======
  chat_messages = []

  # 3a. 添加示例对话
  chat_messages.extend(formatExamples(input.character.character.mes_example))

  # 3b. 添加聊天历史（反向遍历，token 预算裁剪）
  budget = input.token_budget - calcBudget(system_messages)
  for msg in reversed(input.chat_history):
    # 在 at_depth 位置插入世界书条目
    depth_from_end = len(input.chat_history) - msg.index
    at_depth_items = [e for e in input.worldbook.at_depth
                      if e.depth == depth_from_end]
    for item in at_depth_items:
      chat_messages.insert(position, formatEntry(item.entry))

    formatted = formatMessage(msg)
    budget -= calcTokens(formatted)
    if budget < 0: break
    chat_messages.insert(0, formatted)

  # ====== 阶段 4: 最终组装 ======
  final_messages = system_messages + chat_messages

  # 注入后历史指令（jailbreak 在聊天历史末尾）
  if jailbreak_content:
    final_messages.append(IRawChatMessage(role='user', content=jailbreak_content))

  return IAssemblyOutput{
    messages: final_messages,
    token_counts: countTokens(final_messages, by_component=True),
    trimmed_components: trackTrimmed(),
  }
```

**Token 裁剪优先级:**
```
1. 中期摘要（保留最新的）
2. 世界书条目（按 priority 升序丢弃）
3. 示例对话（从最旧开始丢）
4. 聊天历史（从最旧消息开始丢）
```

#### 3.10.3 核心算法

**创建会话 (createSession):**
```
createSession(params):
  1. 加载 ICharacterCard
  2. 选择开场白:
     if params.greeting_index == 0:
       greeting = card.character.first_mes
     else:
       greeting = card.character.alternate_greetings[params.greeting_index - 1]

  3. 创建 IChatSession

  4. 创建第一条消息:
     IChatMessage(
       role='assistant',
       content=greeting,
       round_index=0,  # 每轮从 0 开始
       index=0,
       has_checkpoint=True,  # 初始消息自动 checkpoint
     )

  5. 调用 CharacterRegistryEngine.build() 初始化角色注册表
  6. WorldBookEngine 状态初始化
  7. 返回 IChatSession
```

**创建分支 (createBranch):**
```
createBranch(params):
  1. 加载源会话
  2. 复制从消息 0 到 from_message_id 的所有消息
  3. 创建新 IChatSession (parent_session_id=source.id, branch_number=next)
  4. 返回新会话
```

**Swipe 逻辑:**
```
createSwipe(message_id, content):
  msg = getMessage(message_id)
  if msg.role != 'assistant': raise Error("Only assistant msgs can swipe")
  swipe = ISwipe(index=len(msg.swipes), content=content)
  msg.swipes.append(swipe)
  return swipe

switchSwipe(message_id, idx):
  msg = getMessage(message_id)
  msg.swipe_index = idx
  msg.content = msg.swipes[idx].content  # 当前显示内容 = 选中 swipe
  return msg
```
