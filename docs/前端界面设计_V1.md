## 1. 路由设计

```
/               → 重定向到 /cards
/cards          → CardGalleryPage（角色卡选择页）
/chat/:sessionId → ChatPage（聊天页）
```

- **`/cards`** 为应用首页，展示所有角色卡
- **`/chat/:sessionId`** 为游玩主界面，通过 sessionId 定位会话
- 无匹配路由 → 404 页面

└──────────────────────────────────────────┘
```

### 4.2 CardItem

- 卡片尺寸：响应式网格，最小 240px
- 封面图：16:9 比例，圆角，hover 时轻微放大
- 名称：字体 semibold，单行截断
- 简介：最多两行，灰色
- 标签：小圆角徽章，不同分类不同颜色
- 评分：⭐ + 数字
- 点击：进入聊天页（有会话则进最近的，无则新建）

### 4.3 交互

| 操作 | 行为 |
|------|------|
| 点击角色卡 | 查 `IChatSession` 中 `card_id` 匹配的会话 → 有则跳转 `/chat/latestSessionId`，无则创建新会话 → 发送开场白 → 跳转 |
| 搜索 | 按 `name` / `description` / `tags` 过滤，实时搜索 |
| 标签过滤 | 多选标签，取交集 |

### 5.1 布局

```
┌────────────────────────────────────────────┐

│                                            │

│  ┌──────────────────────────────────┐      │
│  │ 爱丽丝  10:30                    │      │
│  │ 你好呀，旅行者！欢迎来到迷雾森林。  │      │  ← MessageBubble
│  │                     [🔄 备选回复] │      │
│  └──────────────────────────────────┘      │
│                                            │
│         ┌──────────────────┐               │
│         │ 我来了！这里有什么有趣的吗？│     │
│         └──────────────────┘               │
│                                            │
│  ┌──────────────────────────────────┐      │

│  └──────────────────────────────────┘      │
│                                            │
├────────────────────────────────────────────┤
│  📎 🖼️ [输入框...]                [发送] ● │  ← ChatInput + FloatingBall
└────────────────────────────────────────────┘
```

### 5.2 ChatTopBar

- 返回按钮：`←` 图标，跳转到 `/cards`
- 角色头像 + 名称：居中展示
- 右侧操作区：
  - **背景设置**（`🎨`）：点击打开背景图片选择器
  - **会话菜单**（`⋮`）：Dropdown 包含"会话设置"、"删除会话"

### 5.3 ChatBackground

- 默认展示 `IChatSession.background_image`，若为 null 则使用 `ICharacterCard.cover.image_path`
- 背景图片覆盖整个消息区域，半透明叠加层确保文字可读（`bg-opacity-80` + `backdrop-blur-sm`）
- 用户通过 TopBar 的 🎨 按钮可以上传自定义图片替换背景

### 5.4 MessageBubble

- 用户消息（role=user）：右对齐，蓝色/主题色背景
- 角色消息（role=assistant）：左对齐，灰/白背景，显示角色名
- 消息内容支持：纯文本、Markdown 渲染、图片
- SwipeIndicator：当消息有多个 swipe 时显示 `◀ 1/3 ▶`，点击切换
- MessageActions：hover 时出现"编辑"、"删除"、"锁定"图标按钮

### 5.5 ChatInput

- 多行文本输入框（antd Input.TextArea），支持 Enter 发送（Shift+Enter 换行）
- 左侧附件按钮：`📎` 点击弹出图片/文件选择器
- 右侧发送按钮：`➤` 圆形按钮
- 输入框加载状态：发送中显示 loading 动画和取消按钮

## 6. 悬浮球系统

### 6.1 触发器

- 位置：右下角固定（`fixed bottom-6 right-6`）
- 样式：圆形按钮，默认显示 `●` 或齿轮图标，带微光动效
- 点击：展开四个选项的垂直列表

### 6.2 展开列表

```
         ┌────────────────────┐
         │  👥  角色          │  → 打开 CharacterPanel
         ├────────────────────┤
         │  ⚙️  预设          │  → 打开 PresetPanel
    ● →  ├────────────────────┤
         │  📖  世界书        │  → 打开 WorldBookPanel
         ├────────────────────┤
         │  🧠  记忆          │  → 打开 MemoryPanel
         └────────────────────┘
```

- 列表在触发器上方弹出（`popover` 风格）
- 每项左侧为图标，右侧为文字
- 点击一项打开对应的 Drawer，列表自动收起
- 点击触发器或点击外部区域收起列表

## 8. 组件面板详解

### 8.1 CharacterPanel（Drawer）

**触发路径：** 悬浮球 → 角色

```
┌───────── Drawer ─────────────────────────┐
│  标题: 👥 角色管理              [关闭 ×]  │
│                                           │
│  当前角色: [爱丽丝 ▾]                     │  ← CharacterSelector
│                                           │
│  ┌───────────────────────────────────┐    │
│  │  🖼️ 角色配图                      │    │
│  │  ┌──┐ ┌──┐ ┌──┐ ┌────┐          │    │
│  │  │图1│ │图2│ │图3│ │+上传│          │    │  ← ImageGallery
│  │  └──┘ └──┘ └──┘ └────┘          │    │
│  └───────────────────────────────────┘    │
│                                           │
│  ┌───────────────────────────────────┐    │
│  │ ❤️ 好感度                85      │    │
│  │ ⚔️ 战斗力                320     │    │  ← AttributeList
│  │ 🧠 智力                  128     │    │
│  │ 📍 位置                  迷雾森林 │    │
│  │ 🏷️ 状态                  正常    │    │
│  │ 💬 描述                  勇敢... │    │
│  └───────────────────────────────────┘    │
│                                           │
│  [属性图标映射表]                          │
│  ｜ 好感度 → ❤️  ｜ 战斗力 → ⚔️          │
│  ｜ 智力   → 🧠  ｜ 位置   → 📍          │
│  ｜ 状态   → 🏷️  ｜ 职业   → 🛡️          │
│  ｜ 年龄   → 🎂  ｜ 种族   → 🧝            │
│  ｜ 阵营   → 🏳️ ｜ 等级   → ⬆️            │
└────────────────────────────────────────────┘
```

**交互流程：**
1. 打开时默认展示角色选择器中当前选中的角色
2. 切换角色 → 面板内容切换到对应角色的配图和属性
3. 上传配图 → 调用文件选择器（支持 png/jpg/webp），上传后追加到 `images` 数组
4. 属性为只读展示（属性由模型通过 skill 修改，用户通过状态栏弹窗查看）

**属性图标映射规则：**
属性键和图标通过前端映射表关联。映射表包含常见属性名映射，未匹配的属性使用默认图标 `📌`。映射表可扩展。

### 8.2 PresetPanel（Drawer）

**触发路径：** 悬浮球 → 预设

```
┌───────── Drawer ─────────────────────────┐
│  标题: ⚙️ 预设配置              [关闭 ×]  │
│                                           │
│  当前预设: [Izumi Default ▾]              │  ← PresetSelector
│                                           │
│  ┌─ 模型参数 ────────────────────────┐    │
│  │ 🌡️ 温度         0.8  [====●===] │    │  ← SliderParams
│  │ 🎯 Top-P         0.95 [========●]│    │
│  │ 🔢 Top-K         40   [===●=====]│    │
│  │ 📏 Max Tokens    2048 [====●===] │    │
│  │ ⚡ Frequency P.  0.3  [==●======]│    │
│  │ 💫 Presence P.   0.2  [==●======]│    │
│  └────────────────────────────────────┘    │
│                                           │
│  ┌─ 提示条目 ─────────────────────────┐    │
│  │ ☑ main       系统提示... [编辑]    │    │  ← PromptList
│  │ ☑ charDesc   角色描述... [编辑]    │    │
│  │ ☑ scenario   场景设定... [编辑]    │    │
│  │ ☑ jailbreak  越狱提示... [编辑]    │    │
│  │ [+ 添加条目]                        │    │
│  └────────────────────────────────────┘    │
│                                           │
│  [默认预设] [保存为预设]                   │
└────────────────────────────────────────────┘
```

**交互流程：**
1. 打开时展示当前会话使用的预设
2. 切换预设 → 更新 `IChatSession.preset_name`
3. 滑块参数调整 → 实时更新，点击"保存为预设"持久化到全局预设库
4. 提示条目 → 点击编辑打开内嵌编辑器，修改后保存到预设

**参数覆盖规则：**
- 面板中的参数值 = `IPreset` 参数值
- 如果预设中某参数未设置（null），则回退到 `IModelConfig` 中的默认值
- "默认预设"按钮将当前预设设为角色卡的 `preset_name`

│                                           │
│  当前查看: [奇幻世界设定 ▾]               │  ← 选择要查看的世界书

```

**交互流程：**
1. 顶部展示当前角色卡绑定的世界书（勾选 = 启用），用户可勾选/取消
2. 取消勾选 → 从 `IChatSession.worldbook_ids` 中移除
3. 勾选 → 添加到 `IChatSession.worldbook_ids`
4. "[+ 添加世界书]" → 弹出全局世界书选择器，选择后追加
5. 选择一个世界书 → 展示其条目列表，已激活条目标记状态
6. 点击条目 → 打开内嵌编辑器，可编辑关键词和内容
7. 世界书的修改保存到全局 `IWorldBook` 资源

## 9. 状态管理

### 9.1 Zustand Store 结构

```typescript
// ====== Store 切片 ======

interface SessionStore {
    // 当前会话
    currentSession: IChatSession | null;
    currentCard: ICharacterCard | null;
    
    // 聊天状态
    messages: IChatMessage[];
    isGenerating: boolean;
    
    // 操作
    loadSession: (sessionId: string) => Promise<void>;
    sendMessage: (content: string, images?: IContentPart[]) => Promise<void>;
    stopGeneration: () => void;
    swipeMessage: (messageId: string, direction: 1 | -1) => void;
}

interface CharacterStore {
    // 角色注册表
    registry: ICharacterRegistry | null;
    selectedCharacterId: string | null;
    
    // 配图
    uploadCharacterImage: (characterId: string, file: File) => Promise<void>;
    deleteCharacterImage: (characterId: string, imageId: string) => void;
    
    // 操作
    selectCharacter: (characterId: string) => void;
}

interface PresetStore {
    // 预设列表
    presets: IPreset[];
    currentPresetName: string | null;
    
    // 操作
    loadPresets: () => Promise<void>;
    switchPreset: (name: string) => void;
    updatePresetParam: (param: string, value: number) => void;
    savePreset: () => Promise<void>;
}

interface WorldBookStore {
    // 世界书列表
    worldBooks: IWorldBook[];
    activeWorldBookIds: string[];
    selectedEntry: IWorldEntry | null;
    
    // 操作
    loadWorldBooks: () => Promise<void>;
    toggleWorldBook: (id: string, enabled: boolean) => void;
    updateEntry: (entryId: string, content: Partial<IWorldEntry>) => void;
}

interface MemoryStore {
    summaries: IMemorySummary[];
    config: IMemoryConfig | null;
    toggleLock: (summaryId: string) => void;
}

interface UIStore {
    // UI 状态
    floatingBallOpen: boolean;
    activePanel: 'character' | 'preset' | 'worldbook' | 'memory' | null;
    statusBarModalOpen: boolean;
    
    // 操作
    toggleFloatingBall: () => void;
    openPanel: (panel: UIStore['activePanel']) => void;
    closeAll: () => void;
}
```

### 9.2 Store 间依赖

```
SessionStore (主导)
  ├── 加载会话时初始化 CharacterStore
  ├── 切换预设时调用 PresetStore
  └── 发送消息后触发消息列表更新

CharacterStore (独立)
  └── 操作变更通过 API → 后端 → ICharacterChangeLog

PresetStore (全局共享)
  └── 修改保存到全局预设库

WorldBookStore (全局共享)
  └── 修改保存到全局世界书库

MemoryStore (只读)
  └── 由后端 MemorySystem 生成
```

## 10. 关键数据流

### 10.1 进入会话

```
用户点击角色卡
  ↓
GET /api/cards/:cardId/sessions → 查该卡的所有会话
  ├── 有会话 → 返回最近的 sessionId → 跳转 /chat/:sessionId
  └── 无会话 → POST /api/sessions (cardId)
       ├── 创建 IChatSession（greeting_index=0）
       ├── 从 card.npcs 初始化 ICharacterRegistry
       ├── 从 card.first_mes 创建第一条 IChatMessage
       └── 返回新 sessionId → 跳转 /chat/:sessionId
  ↓
ChatPage 加载:
  ├── 加载 IChatSession → 设置 SessionStore
  ├── 加载 ICharacterCard → 设置背景图
  ├── 加载 IChatMessage[] → 渲染消息列表
  ├── 重建 ICharacterRegistry → 初始化 CharacterStore
  └── 加载记忆摘要 → 初始化 MemoryStore
```

### 10.2 发送消息

```
用户输入 → 点击发送
  ↓
ChatInput 提交:
  ├── 将用户输入保存为 IChatMessage (role=user)
  ├── 追加到 messages 列表（即时展示）
  ├── POST /api/chat (sessionId, input, images)
  └── 进入生成状态（isGenerating = true）
  ↓
后端处理管线:
  ├── 加载 ICharacterCard + IChatSession
  ├── WorldBookEngine 扫描 → IWorldBookActivationResult
  ├── MemorySystem 查询 → IMemoryOutput
  ├── PromptManager 排序 → IPromptCollection
  ├── ContextAssembler 组装 → IAssemblyOutput
  ├── LLM 调用（含 character management tool definitions）
  │     ├── 有 tool_call → 执行 → 写 ICharacterChangeLog
  │     │                → 更新 ICharacterRegistry
  │     │                → 二次 LLM 调用（带 tool_result）
  │     └── 无 tool_call → 返回最终响应
  ├── 保存 IChatMessage (role=assistant)
  └── SSE 流式返回 IGenerateChunk
  ↓
前端接收:
  ├── 逐 token 渲染 assistant 消息
  ├── 完成 → 追加到 messages 列表
  ├── 更新 CharacterStore（如有角色变更）
  ├── 每 10 轮触发记忆摘要生成
  └── isGenerating = false
```

### 10.3 角色配图上传

```
用户在状态栏/角色面板点击 [+ 上传]
  ↓
文件选择器（accept="image/png,image/jpeg,image/webp"）
  ↓
POST /api/sessions/:sessionId/characters/:charId/images (form-data)
  ├── 后端保存图片到存储（本地文件系统 / 对象存储）
  ├── 创建 ICharacterImage 记录
  ├── 追加到 IStoryCharacter.images
  └── 返回 image url
  ↓
前端:
  ├── 更新 CharacterStore
  └── 刷新配图展示
```

### 10.4 消息回溯 & 角色状态回溯

```
用户点击回溯到 message_index = N
  ↓
POST /api/sessions/:sessionId/rollback (targetIndex: N)
  ↓
后端:
  ├── 删除 message_index > N 的 IChatMessage
  ├── 删除 message_index > N 的 ICharacterChangeLog
  ├── 重建 ICharacterRegistry (从 card.npcs + 保留的 changeLogs)
  └── 重新生成 IMemoryOutput
  ↓
前端:
  ├── 重新加载 message 列表
  ├── 重新加载 CharacterRegistry
  └── 刷新 UI
```
